# Pemfilteran-Air

Program untuk mendeteksi kekeruhan air menggunakan sensor turbidity serta untuk mengerakkan motor servo jika air melebihi batas kekeruhan sebelum dilakukan pemfilteran saat pembuangan air dengan menggunakan mikrokontroller Arduino Uno untuk memproses program serta logika program serta LCD I2C untuk menampilkan kondisi air serta nilai kekeruhan air dalam satuan NTU. (Studi Kasus pada pembuangan limbah air dari kolam lele ke sungai)
